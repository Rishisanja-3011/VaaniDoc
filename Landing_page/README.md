# VaaniDoc Landing Page

Single public entry point for the hackathon submission.

Configured destinations:
- Doctor Dashboard: https://vaani-doc-doctordashboard.vercel.app
- Patient App: https://vaani-doc-kappa.vercel.app

## Run locally
npm install
npm run dev

## Build
npm run build

## Vercel
Create a new Vercel project with this `landing-page` folder as the project root.
Framework: Vite
Build command: npm run build
Output directory: dist
Install command: npm install
No environment variables are required.

Submit only the deployed landing-page URL to the organizers.
